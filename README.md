# B站粉丝屏

把闲置安卓手机变成 B站粉丝数显示屏。无需登录 B站，手机直接联网使用，无需电脑常开。

**[下载最新版 APK](https://github.com/weeazn/bili-fans-screen/releases/latest)** · [详细使用说明](android/使用说明.md) · [反馈问题](https://github.com/weeazn/bili-fans-screen/issues)

## 主要功能

- 大字粉丝数、本机走势图、多账号轮播与涨粉连击动画。
- 自动横竖屏、挖孔避让、莫奈与自定义配色。
- 自定义昵称、简介和相册头像，支持恢复原始资料。
- 前台常亮、断网重试、原生 OLED 防护与定时全屏图片 / 视频休息。
- 离线演示：长按编辑粉丝数和资料，设置随机涨粉速度，随时清空演示数据。

## 开始使用

1. 下载并安装正式 APK，支持 **Android 6.0～Android 17**。
2. 按首次引导填写 UP 主 UID，即 B站空间地址末尾的数字。
3. 在设置中选择常亮、屏幕方向和配色，把应用留在前台即可。

默认约 90 秒刷新一次。走势图从本机开始记录，设置和自定义资料保存在本机；卸载或清除应用数据会丢失。

正式版可覆盖同签名旧正式版；旧测试版使用不同签名，不能直接覆盖。

## 开发与网页版

安卓编译步骤见[使用说明](android/使用说明.md#重新编译)。

网页版需安装 Node.js 18+，在项目目录运行：

```sh
node server.js
```

浏览器打开 `http://localhost:8787`。手机访问电脑的局域网地址时，需要连接同一 Wi-Fi，并保持服务运行。

## 关于

非 B站官方应用，数据更新受网络和公开接口限制。常亮仅在前台生效；OLED 防护只能降低烧屏风险。
