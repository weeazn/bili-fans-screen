# B站粉丝屏 · 安卓版

## 1.3.1 修复

- 图表使用独立绘图区，横竖屏切换后按实际像素尺寸重绘，避免 SVG 反向撑高容器及比例失真。
- 防烧屏的降亮度仅作用于看板，设置面板保持正常显示；位移改为瞬时跳变，转屏动画不再覆盖降亮度效果。微位移只能降低风险，不能保证避免 OLED 老化。
- 演示模式设置新增「清空演示数据」，确认后恢复默认演示数量、资料、增长设置并清除旧演示走势；保留真实账号和通用显示设置。

## 1.3 连击动画与演示资料

- 涨粉显示弹出数字，5 秒内连续增长累计为连击；设置可关闭界面与涨粉动画。
- 昵称、简介、相册头像可在设置中修改，仅影响本机显示；图片自动居中裁切为 1:1。恢复默认资料后，使用 UID 对应的原始资料。每个 UID 与演示资料独立保存。
- 演示模式长按粉丝数字修改数量，长按头像区域编辑资料；设置中隐藏 UID、刷新和联网选项。
- 每个模拟日从指定的 1～10000 范围随机选取涨粉量，按时间分摊。可选择正常、60 倍或 3600 倍演示速度，仅前台计时，关闭后暂停。
- 演示粉丝上限为 1,000,000,000，达到后提示并停止增长，重开仍停止；主动调低数量才能恢复。真实 B站统计不支持人为编辑。
- 设置、真实账号缓存、头像、演示数量及走势保存在本机。覆盖安装保留数据；卸载或清除应用数据会删除。
- 安卓侧边返回先关闭资料编辑，再关闭设置回到看板；在看板返回才打开安卓专用菜单。
- 屏幕方向选择「自动旋转」即可跟随手机横放、竖放。

## 1.2 首次引导与个性化

新安装不预设任何 UID。首次开屏会播放简短动画，按三步引导填写你自己的 UID、选择常亮与挖孔避让，确认后才开始查询。升级安装会保留已保存的 UID，不会清空原用户数据。

- 纯黑背景开关现在真正控制黑色主题；OLED 防烧屏位移单独开关。
- 配色支持默认粉色、系统莫奈取色和自定义。莫奈取色需要 Android 12 及以上，不支持时会提示并使用默认色。
- 设置中可固定横屏、固定竖屏或自动旋转，切换带淡入过渡；系统开启减少动画时会缩短动画。
- 挖孔 / 刘海避让默认开启，额外安全边距可设为 0～48 dp，切换方向后仍然生效。
- 设置内包含 weeazn 作者主页、常亮操作步骤，以及系统显示、应用电池和开发者选项的快捷入口。

## 1.1 排版更新

顶栏按钮独立分栏，走势图说明和时间按钮分行，设置面板按钮统一排版。竖屏按账号、数字、涨跌、走势图、作品和状态依次排列；空间不足时可以滚动。较矮的横屏会隐藏作品列表，优先显示数字与走势图。安卓窗口增加系统栏、刘海和键盘区域适配。新版沿用原签名，可直接覆盖安装保留应用数据。

这是面向闲置安卓手机的独立应用，支持 Android 6.0～Android 17。UID 由用户自行填写，作者主页仅用于作者信息。手机直接联网读取粉丝数、账号资料和最新作品，无需电脑常开、无需 B 站账号密码。

## 安装与使用

1. 公开分发使用 `dist/发布版/B站粉丝屏-1.3.1.apk`，将其传到手机安装；按系统提示允许该文件来源安装应用。正式版沿用 1.2 发布签名，不能覆盖调试签名版。老测试用户要保留本机历史，可安装单独提供的「旧版覆盖升级」包；该包不用于公开分发。
2. 打开「B站粉丝屏」，按首次引导填写 UID。刷新间隔建议默认 90 秒。首次取数需要联网；B站接口可能限流，失败时会自动退避重试。
3. 保持「保持屏幕常亮」开启。App 使用安卓系统常亮标志，无需依赖浏览器的 Wake Lock 支持。
4. 在主看板按手机返回键，或点齿轮面板里的「安卓常驻 / 开机恢复设置」，打开安卓专用菜单，调节应用亮度。设置页面按返回键会回到看板。
5. 专用显示机建议在菜单中选择「设为默认桌面」，并按系统提示选择此应用。这样按 Home 会回到看板，系统进入桌面时也会显示看板。重启后通常需要先解锁一次；实际启动行为受系统和厂商限制。
6. 在系统应用设置中，将本应用的电池策略设为「不限制」，允许自启动（如有），并在最近任务里锁定。各品牌菜单名称不同。

## 保活覆盖范围

| 情况 | 处理方式 |
| --- | --- |
| 前台长时间显示 | 系统常亮、全屏、应用内亮度调整 |
| Wi-Fi 断开后恢复 | 保留上次数字、自动重试，网络恢复触发刷新 |
| B站请求失败 | 粉丝数指数退避；视频缓存 30 分钟，失败退避 15～120 分钟 |
| 页面 JS 无心跳超过 90 秒 | 在应用前台时重新创建 WebView；设置和历史保存在应用存储 |
| WebView 渲染进程被回收 | 重新创建页面 |
| 多账号轮播 | 每次切换都刷新对应账号，避免一直显示旧缓存 |
| 手机重启 / Home 返回 | 可选默认桌面模式；受首次解锁和系统限制 |
| 系统强制停止 / 手机关机 / 断电 | 无法保证自动恢复，需要重新打开应用或恢复供电 |

该应用以**前台专用显示**为目标。切换到其他应用或锁屏后，不承诺后台持续更新；回到应用后继续刷新。没有使用静音播放、无期限 CPU 唤醒锁或后台循环拉起页面。

## 恢复原来的手机桌面

按返回键 →「系统设置 / 恢复原桌面」→ 系统默认应用 → 桌面应用，选择原桌面。也可以从屏幕顶部下拉通知栏进入系统设置。退出按钮不会清除默认桌面选择，需先恢复原桌面。

## 数据与显示

- 设置、走势图和上次数字保存在本机。清除应用数据或卸载会删除这些记录。
- 默认不启用公共第三方代理。原生请求只访问固定的 B站 HTTPS 接口；头像由 WebView 加载。
- 仍支持原设置中的自建代理，作为粉丝数的可选回退。安卓内置最新作品接口直接访问 B站。
- 视频缓存和失败退避状态会落盘，重启 App 不会触发密集重试。
- OLED 可在齿轮面板开启防烧屏位移，配合低亮度使用；此功能不能保证完全避免烧屏。
- 老手机需要能运行现代 JavaScript 的 Android System WebView。页面空白时先更新系统 WebView / Chrome。

## 重新编译

项目使用 JDK 17、Android SDK 35、Gradle 8.11.1、Android Gradle Plugin 8.9.1。

用 Android Studio 打开 `android` 文件夹，安装 SDK 35 并同步 Gradle，然后 Build → Generate App Bundles or APKs → Generate APKs。或者配置好 JDK 17 和 `ANDROID_HOME` 后，从根目录执行：

```powershell
.\android\gradlew.bat -p android assembleDebug
```

编译会自动把根目录 `index.html` 复制到应用资源，避免维护两份页面。调试包位于 `android/app/build/outputs/apk/debug/app-debug.apk`。正式发布请执行 `assembleRelease`，输出位于 `android/app/build/outputs/apk/release/app-release.apk`。正式包关闭调试功能，使用项目 `.signing` 文件夹中的私有签名材料。后续更新必须继续使用同一个签名；请单独安全备份整个 `.signing` 文件夹，不要将它上传到网站或公开仓库。公开发布只上传 `dist/发布版` 内的文件或发布压缩包。

## 验收建议

在实际手机上检查：首次联网取数、飞行模式后恢复 Wi-Fi、横竖屏切换、关闭再打开、默认桌面模式下重启解锁。最后连续运行一晚，确认更新时间持续变化。
